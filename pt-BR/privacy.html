Não. O Sereno: Sons para Dormir não tem assinatura. O conteúdo pago é uma compra única, sem cobrança recorrente. Os recursos básicos são gratuitos. Para liberar tudo, o Sereno: Sons para Dormir oferece uma compra única no app. Você pode testar a parte gratuita com calma antes de comprar. Continua. Entre com a mesma conta Apple e toque em “Restaurar compras” no app: a compra é reativada sem pagar de novo.

Como apago meus dados?

Apague o item dentro do app. Para limpar tudo de uma vez, mantenha o ícone do Sereno: Sons para Dormir pressionado na tela de início e apague o app: os dados guardados no aparelho vão junto (um backup do aparelho ainda pode conter uma cópia).
